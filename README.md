# ti-corporate-website

Sitio web corporativo para empresa de ingeniería de sistemas y servicios TI.

## Descripción
Landing page profesional para una empresa de soluciones tecnológicas, orientada a captar clientes corporativos, mostrar servicios, generar confianza y facilitar contacto.

## Objetivo
Diseñar una presencia digital moderna, clara y con enfoque comercial para una empresa de ingeniería de sistemas y servicios TI.

## Servicios principales
- Consultoría tecnológica
- Soporte empresarial TI
- Seguridad informática
- Infraestructura y redes
- Desarrollo a medida
- Automatización de procesos

## Tecnologías utilizadas
- HTML
- CSS
- JavaScript

## Estructura del proyecto
- `index.html`
- `style.css`
- `script.js`
- `README.md`

## Características
- Diseño moderno y corporativo
- Sección de servicios
- Sección de nosotros
- Sección de proyectos
- Llamado a la acción
- Contacto y redes sociales
- Diseño responsivo

## Cómo usar
1. Clona el repositorio.
2. Abre `index.html` en tu navegador.
3. Personaliza textos, colores y contenido según tu empresa.
4. Si deseas, puedes publicar la página con GitHub Pages.
